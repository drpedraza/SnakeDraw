# 🐍 SnakeDraw

Un proyecto simple y divertido del clásico juego de la **Viborita (Snake)** desarrollado en **Kotlin** utilizando **Android Studio**. El juego se dibuja en un `Canvas` personalizado y puede controlarse por gestos táctiles.

## 🎮 Características

- Dibujo del juego mediante `Canvas` personalizado.
- Control de la viborita mediante toques en la pantalla:
  - Toca arriba para moverte hacia arriba.
  - Toca abajo para moverte hacia abajo.
  - Toca a la izquierda o derecha para moverte en esas direcciones.
- Movimiento automático de la serpiente cada 500ms.
- Generación aleatoria de comida.
- Reinicio automático al colisionar con uno mismo.
- Código estructurado en componentes (`Lienzo`, `Direccion`, `Tablero`).

## 🛠️ Tecnologías utilizadas

- Kotlin
- Android Studio
- Canvas API
- Arquitectura MVC simplificada
